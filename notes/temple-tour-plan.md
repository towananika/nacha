# ナチャのお寺めぐり — 企画案（2026-11-06）

## ひとこと
なちゃと一緒にカンボジアのお寺をめぐる。道中は景色を楽しみ、着いたら館内を整える。整えるたびに悪気が晴れ、御朱印風の印が貯まり、最後は游遊観音堂で四柱がそろう。

## 狙い
- 遊んだ人が、なちゃ・四柱・游遊観音堂の世界観を、自然に知る。
- 静かで、やさしく、ゲームとして満足感がある（点数より「整った」満足）。
- 興味が出たら、最後にFollow（X / IG）へ。お金・トークンの話は出さない。

## 全体の流れ（1回のプレイ 約3分）
1. **出発**: なちゃが旅に出る。「悪気が寺にしみ込んだ。整えに行こう！」（1行）
2. **道中（約20秒）**: 景色がゆっくり流れる。操作は「道ばたのものをタップ」だけ。タップすると小さなひとこと（例: 「Nice view!」）が出る。見るだけでもよい。
3. **到着 → 整える（30〜60秒）**: 散らかった館内を元に戻す（下に詳細）。
4. **浄化**: 全部そろうと、暗い画面がぱっと明るくなる。なちゃの反応と印（スタンプ）が貯まる。
5. **次の寺へ**: 5か所で1周。最後は游遊観音堂で四柱の出迎え → Follow。

## 「整える」の遊び方（1か所の仕組み）
- 画面に、散らかったもの（6〜8個）と、置き場所の枠が出る。
- ものをタップ → 置き場の枠をタップ、でそこに収まる（ドラッグでも可）。間違えると「ぷるっ」と戻る（罰なし）。
- 悪気のもや（暗い霧）がかかっていて、ものを戻すたびに薄くなる。全部で霧が晴れる。
- **ゲーム性**: 制限時間なし。代わりに「手数」と「手早さ」で星1〜3。星で印の色が変わる（銅・銀・金）。
- 5か所目で、星の合計に応じて四柱の反応が変わる。
- 一度に置けるもの・枠の数を場所ごとに増やして、少しずつ難しくする。

## ナチャらしさをどこに入れるか
- なちゃが案内役で、すべての場面に一緒にいる（座る、のぞく、手伝う）。
- 悪気 → 整えて浄化、という世界のルール。
- 四柱: 白衣観音（やさしい声）、不動明王（きっぱり）、南極老人（のんびり）。道中でそれぞれ1回だけ現れる。
- 一言はNACHA's Wordの口調（短く、あたたかく、まっすぐ）。

## 修行・段位との連携

- 印（スタンプ）は端末内に保存。サーバー・ログイン不要。
